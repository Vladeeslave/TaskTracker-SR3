# TaskTracker

Консольний застосунок для обліку завдань команди на дошці Kanban: створення завдань, переміщення між колонками з контролем ліміту незавершеної роботи та звіт про завантаження виконавців.

**Варіант 15 · <Прізвище Ім’я> · група <номер> · дисципліна «Конструювання програмного забезпечення»**

## Швидкий старт

```
git clone https://github.com/<ваш-логін>/TaskTracker.git
cd TaskTracker
dotnet run --project src/TaskTracker.Cli
```

Потрібен .NET 8 SDK. Під час першого запуску застосунок сам створює файл `data/board.json` з умовними даними.

## Структура рішення

- `src/TaskTracker.Domain` — завдання, колонки, таблиця переходів, правило ліміту незавершеної роботи, власні винятки.
- `src/TaskTracker.Application` — сценарії UC-01…UC-06, інтерфейси сховищ, годинника й журналу, перевірка вводу.
- `src/TaskTracker.Infrastructure` — сховище JSON, системний годинник, файловий журнал, генератор умовних даних.
- `src/TaskTracker.Cli` — меню й композиційний корінь.
- `tests/TaskTracker.Tests` — модульні тести (xUnit).
- `docs/` — специфікація, архітектура, посібник користувача, журнал рішень, самооцінка.

## Можливості

Сценарії докладно описано в [docs/spec.md](docs/spec.md):

- UC-01 створити завдання;
- UC-02 перемістити завдання дошкою (таблиця переходів і WIP-ліміт);
- UC-03 призначити виконавця;
- UC-04 записати витрачений час;
- UC-05 знайти завдання;
- UC-06 переглянути завантаження виконавців.

## Тести й покриття

```
pwsh ./scripts/check.ps1
```

Скрипт виконує ті самі перевірки, що й конвеєр GitHub Actions: формат, складання Release без попереджень, тести, поріг покриття. Поточне рядкове покриття бібліотеки логіки (Domain і Application): **<число> %** (покриття гілок: <число> %). Інфраструктура й консоль до вимірювання не входять.

## Технології

.NET 8, C# 12, xUnit, coverlet, аналізатори Roslyn і StyleCop, GitHub Actions.
