# Непокриті гілки бібліотеки логіки

Таблицю складено за звітом про покриття (`coveragereport/index.html`). Причини: недосяжна (захист від помилки програміста), поза межами вимірювання, свідомо не реалізовано, борг.

| Місце | Гілка | Чому не покрито | Рішення |
|---|---|---|---|
| TaskBoardService, конструктор | ?? throw для directory, clock, log | недосяжна: захист від помилки програміста | тест не потрібен |
| TeamMember, Project (конструктори) | ArgumentException для порожнього імені | недосяжна: екземпляри створює лише генератор і тести | лишити як захист |
| TimeEntry, конструктор | години поза межами | недосяжна: сервіс перевіряє години раніше (InputRules) | лишити як захист |
| WorkTask.Restore | ArgumentNullException | недосяжна: знімок завжди існує | лишити |
| Result.Fail | порожній текст помилки | недосяжна: усі виклики передають текст | лишити |
