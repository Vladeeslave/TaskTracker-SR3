## Повідомлення про помилки

| Повідомлення | Що означає | Що робити |
|---|---|---|
| Назва не може бути порожньою. | назву не введено | ввести назву до 100 символів |
| Проєкту з кодом XX-99 немає. | невідомий код проєкту | використати код із довідника, наприклад TT-01 |
| Години мають бути числом, наприклад 2,5. | введено не число | вводити число, дробову частину через кому |
| Години мають бути більшими за нуль і не більшими за 200. | число поза межами | ввести значення з допустимого діапазону |
| Відхилено: З колонки Done подія Start заборонена. | перехід не дозволено таблицею | обрати іншу подію (розділ 1.5 специфікації) |
| Відхилено: У завдання немає виконавця. | завдання без виконавця не можна взяти в роботу | призначити виконавця (пункт 3) |
| Відхилено: У виконавця вже 3 завдань у роботі, ліміт — 3. | досягнуто WIP-ліміт | завершити або передати на перевірку одне із завдань виконавця |
| Збій: … Подробиці в logs/app.log. | непередбачена помилка | переглянути журнал і повідомити розробника |

## Дані й резервна копія

Дані лежать у файлі `data/board.json`, журнал — у `logs/app.log`. Резервна копія — копія файлу `data/board.json` (наприклад, `Copy-Item data\board.json data\board.backup.json`). Якщо файл видалити, під час наступного запуску створяться умовні дані.
