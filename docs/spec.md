# Специфікація функцій TaskTracker

Варіант 15. Консольний застосунок обліку завдань команди на дошці Kanban.

## 1.1. Межі системи

| Входить | Свідомо не входить |
|---|---|
| облік завдань, виконавців і проєктів | авторизація й розмежування прав користувачів |
| переміщення завдань між колонками за таблицею переходів | кілька дошок і власні колонки |
| ліміт незавершеної роботи (WIP) для виконавця | коментарі, вкладення, сповіщення |
| облік витраченого часу | інтеграція з Jira та іншими трекерами |
| пошук завдань за колонкою, виконавцем і назвою | графічний інтерфейс, вебдоступ |
| звіт «завантаження виконавців» | історія змін завдання (аудит) |
| збереження даних у файлі JSON | база даних, одночасна робота кількох користувачів |

## 1.2. Словник домену

| Термін | Ідентифікатор | Значення |
|---|---|---|
| завдання | WorkTask | документ зі станом, оцінкою й записами часу |
| колонка дошки | WorkTaskStatus | стан завдання: New, InProgress, Review, Done, Cancelled |
| подія переходу | TaskEvent | дія, що переміщує завдання: Start, SendToReview, Return, Complete, Cancel |
| таблиця переходів | TaskTransitions | перелік дозволених пар «колонка — подія» |
| виконавець | TeamMember | учасник команди, якому призначено завдання |
| проєкт | Project | довідник проєктів; завдання належить одному проєкту |
| запис часу | TimeEntry | скільки годин і коли виконавець працював над завданням |
| оцінка | WorkTask.EstimateHours | планова трудомісткість завдання в годинах |
| ліміт незавершеної роботи | WipPolicy.WipLimit | найбільша кількість завдань виконавця в колонці InProgress (3) |
| завантаження | WorkloadRow.LoadPercent | частка від WIP-ліміту у відсотках |
| критерії пошуку | TaskFilter | колонка, виконавець, фрагмент назви |
| журнал | IAppLog | файл подій: час, рівень, сценарій, повідомлення |
